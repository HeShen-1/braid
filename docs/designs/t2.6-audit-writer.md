- 决策条目:`D-2026-09-23-t26-audit-events`(docs/DECISIONS.md),2026-09-23 用户确认。
- 契约真源:internal/db/migrations/0001_init.up.sql §6(audit_log DDL 全注释)。

## 1. 写入器(internal/audit)

镜像 outbox 范式(outbox/append.go):

```go
type Event struct {
    ID          uint64          // snowflake,应用生成,零值被拒
    EventType   string          // 词表见 §2,≤64
    ExecutionID uint64          // exec_date 物化锚
    NodeExecID  uint64          // 0 → NULL(执行级事件,P0 未用)
    NodeID      string          // DSL 节点 id 冗余,空 → NULL
    AttemptID   uint64          // 0 → NULL(attempt 级事件必携)
    ActorType   string          // worker | system(词表开放:user/tool/llm/approval 预留)
    ActorID     string          // 归因必填:workerID / "reaper:<id>"
    TraceID     string          // "" → NULL(T6.2 前占位不伪造)
    Payload     json.RawMessage // 合法 JSON,空 → {}
}

func Append(ctx context.Context, q engine.DBTX, evt Event) error
```

- 同步直写:调用方在状态迁移**同一事务**内调用(与 outbox.Append 并列);event_at = DB 端 NOW(3),与 status_changed_at 同钟系(异步分立归 T6.1)。
- exec_date 物化(T2.6-F1 修订,`D-2026-09-23-t26-audit-writer-lockfree-read`):
  两语句——普通一致读 `SELECT DATE_FORMAT(created_at,'%Y-%m-%d') FROM workflow_execution WHERE id=?`
  直出字符串(零锁,写入器因此在全局锁序之外;字符串不经 driver 的
  time.Location 解析,loc 无关——DATE→time.Time 再 .UTC() 在 loc≠UTC 时会
  静默移日,review 修)→ `INSERT VALUES`(event_at = NOW(3))。
  原单语句 INSERT..SELECT 在 RR 下对源行取共享 next-key 锁持至 COMMIT,reaper
  leaderless 双扫描各持 S 后在 wf FOR UPDATE 升级 X 处 1213(PR #13 review #9,
  t13 双会话复现);一致读把该死锁类在所有调用点结构性消灭。SELECT ErrNoRows
  (execution 缺行)= 数据缺陷,响亮 `ErrNotFound`(不静默无写)。代价 = 每审计
  行一次 PK 点查(P0 量级噪声,批量去重归 T6.1)。其余列(pii_masked/prev_hash/
  row_hash/usage/cost)走 DDL 默认(P0 语义:未启链、未脱敏)。
- 校验(触 DB 前,风格对齐 outbox.ErrInvalidEvent):ID/ExecutionID 非零、EventType 非空 ≤64、ActorType/ActorID 非空(每行必有归因)、TraceID 空或 32 hex 小写、Payload 合法 JSON(空规范化为 `{}`)。
- 错误分类:ErrInvalidEvent(调用方 bug);ErrNotFound(execution 缺行);其余 %w 包装上抛,Transient 判定归调用方(与 outbox 同规)。

## 2. P0 事件词表

| event_type | 触发 | payload | attempt_id 列 |
|---|---|---|---|
| `node.state_changed` | 每次节点状态迁移(全部 CAS 边) | from,to,node_id,version(新),code?,msg?,attempt_no?,worker_id? | 观察者路径携带(Complete/reaper) |
| `node.redispatched` | status-preserving 重派(scheduler 重试 / reaper 重派) | node_id,attempt_no(新),trigger=attempt_failed\|reaped,max_attempts? | — |
| `attempt.reaped` | reaper DEAD 裁决(heartbeat_lost / deadline_exceeded / stale_attempt) | node_execution_id,code,worker_id,stale?/node_status? | **必携** |
| `node.deadline_extended` | reaper 迟到启动一次性重挂 | node_id,attempt_no,deadline_at(新) | — |
| `branch.evaluated` | dispatchBranch 路由决定(D-t24 #3) | node_id,next | — |

actor:worker 路径 = `worker` / workerID;reaper = `system` / `reaper:<id>`。

## 3. 埋点(9 处现有调用面)

engine CAS helper 不内嵌审计(保持纯粹;非迁移事件与迁移事件同走调用方路径)。新调用点接入时必须同事务落行——契约钉在 nodecas.go 头注释。

| 位置 | 事件 |
|---|---|
| scheduler dispatchOne(ClaimNode 后) | node.state_changed PENDING→EXECUTING |
| scheduler dispatchBranch(ClaimNode/SucceedNode 后) | node.state_changed ×2 + branch.evaluated |
| scheduler skipOne(SkipNode 后) | node.state_changed PENDING→SKIPPED |
| scheduler completeOnce(Succeed/Redispatch/Fail 后) | node.state_changed ×2 路径 + node.redispatched(trigger=attempt_failed) |
| reaper reapOnce:CloseAttemptDead ×3 | attempt.reaped(分码) |
| reaper reapOnce:ExtendNodeDeadline | node.deadline_extended |
| reaper reapOnce:CancelNode | node.state_changed →CANCELLED |
| reaper reapOnce:RedispatchNode | node.redispatched(trigger=reaped) |
| reaper reapOnce:FailNode(耗尽) | node.state_changed EXECUTING→FAILED |

## 4. P0 范围外(显式)

wf 级事件(execution.*)、execution.triggered、attempt 创建/观察收口(node_attempt 状态表自证)、哈希链、trace_id、pii_masked、SuspendNode/ResumeNode/RequeueNode/API Cancel(无调用点,词表已定,接入任务落行)。payload 只含 id/码/枚举——密钥永不入内(铁律)。

## 5. 测试

- audit 单测:校验表驱动(非法输入逐项)、ErrNotFound、payload 规范化。
- audit 集成(t13):exec_date = DATE(created_at) 物化断言、列落位(id/event_at/payload)、同事务回滚审计行同亡。
- scheduler/reaper 集成扩展:各路径断言审计行存在且 event_type/actor 正确(验收「每次迁移产生审计行」的守护;新路径靠此模式延续)。
