## 机制与专项

- 打开工作流设置时清掉 React Flow 选中态；再次点击同一节点可切回属性。
  保留手动收起属性面板的既有偏好与删除确认后的焦点回归。
- 命名分支出口连线、目标下拉、删边、删目标和删 case，在同一个 graph
  更新中维护 `cases[].next/default` 与唯一 `(from,to)` 出边。多个条件和
  默认可共用目标；只重连一路时仍保留另一条路由需要的旧目标。
- 导入、无操作保存及只改标题，不按历史 `metadata.source_anchor` 交换
  业务去向。未命名兜底出口可绑定已有业务目标；新目标须从命名出口连接。
- 工作流面补齐已有 `required/description` 字段编辑；触发页复用
  `getVersion(name, version)`，按选中版本展示类型、必填、说明和 JSON 示例。
  旧请求迟到不覆盖新目标，读取失败可重试，缺字段就近提示。
  `false/0/[]/{}` 按字段存在判定，不当作缺失。
- `prompt.system/template` 只写固定指令，禁止任何 `{{...}}`。引用放在
  `user_data.ref`，示例为输入或上游节点输出；运行时以 `name: value`
  追加在模板后，没有模板占位插值。并行 body 的错误模板占位说明也已修正。
- 缩略图可显式折叠，画布高度不大于 20rem 自动隐藏；补未保存、执行页、
  审批节点、触发 busy 与空态文案。F69 的不可选占位已由 T23.6 交付，
  本项只核对并补回归断言。

反例覆盖共目标唯一边、仅改一路、删中间 case 后索引左移、删边/删目标、
历史锚点与业务路由冲突、异步跨版本迟到回包，以及必填参数的零假值。
