## 机制与证据口径

- 审计消费 keyset `next_cursor`，支持加载更多、按已展开深度刷新。计数为
  “已加载 N 条”；末页只指本次读取，异步审计可能稍后到达，不提供虚构总数。
- 时间带保留回滚选点与确认；独立节点证据入口携带真实 node/instance/round，
  按需读取投影、轮次列表与单轮证据。打开滚入可见区域并聚焦，收起返回
  外部入口；Trace 内再次查询仍保留有效外部返回点，poll/翻页不抢焦点。
- `round` 等于该 `(node_id, instance_no)` 内跨回滚累计单调的 `attempt_no`，
  回滚不重新编号。历史轮次 ≤ base，
  当前轮代必须满足 base < round ≤ attempts；列表领先投影时标明未同步。
  Ribbon 显“累计 N 轮”，不将累计轮数除以单轮代最大尝试次数。两次读不是
  事务快照，不伪装同步；空台账/404不猜未物化、清理或越界成因。
- 输入/输出、错误、模型、tokens、cost/币种及 estimated 按既有字段呈现。
  NULL 不合成 0，真实 0 USD 保留；审计和 attempt 双录不相加成总成本。
- 头部/时间带明确为可能含回滚闲置间隔的跨轮墙钟；本轮时长取 attempt
  起止区间，挂起后的两轮间隔不计入，不称 CPU/worker 纯运行计时。
  DEAD 缺少结束时刻时显示未知。时间在拆单位前舍入，修复 7m60s 等进位。
- JSON 结构视图明确标为解析后展示；执行详情、节点投影、轮次列表、单轮
  及每页审计都保留服务端 `text()` 原文，供大整数精确核验。未引入 parser、
  新依赖或更改业务数值类型。原文仍为既有服务端授权投影，不绕过脱敏。
- 事件解释保留真实原码和 payload，未知事件不猜解释。row_hash/prev_hash
  只作完整性关系原值展示，不当 trace，也不冒称已验证哈希链。
  依锁定决策 D-2026-09-25-t63 #4 / D-2026-09-27-t62 / D-2026-10-06-t185，既有 DTO 不返回 linked_trace_id；
  本票展示真实执行根 trace、事件 trace/attempt 关联及 trace 维度查询，
  不推断父子关系，不改后端读协议/状态/事件词表。
